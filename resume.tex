    \PublicationEntry{Dependently Typed Programming with Lexical Effect Handlers}{ESOP 2027}
    {}
    {Cocotte is a dependently typed language that supports user-defined, lexically scoped effect handlers. Prototyped atop the Rocq prover, the system features a proof of compilation correctness and delivers competitive performance.
    }
    {\underline{\textbf{Publication}}: Jin, Ende, and Yizhou Zhang. "Dependently Typed Programming with Lexical Effect Handlers." European Symposium on Programming (ESOP), 2027.}

    \PublicationEntry{Effect Handlers in Lean: A Tale of Two Representations}{Under Review, 2026}
    {}
    {Lix embeds effect handlers into Lean 4 without sacrificing equational reasoning, induction, or performance, all while fitting naturally into Lean's design and implementation. We formally prove the parametricity of effect polymorphism to establish its abstraction guarantee.
    }
    {}

    {}
    {Modular construction of certified compilers using family polymorphism in a proof assistant.
    }
    {\underline{\textbf{Publication}}: Ebresafe, Oghenevwogaga, Ian Zhao, Ende Jin, Arthur Bright, Charles Jian, and Yizhou Zhang. "Certified Compilers \`a la Carte." Proceedings of the ACM on Programming Languages 9.PLDI (2025): 372-395.}

    \PublicationEntry{Extensible Metatheory Mechanization via Family Polymorphism}{PLDI 2023}
    {Distinguished Paper Award}
    {Family inheritance generalizes object-oriented programming by supporting nested classes and inheritance along multiple dimensions.
    This project applies it to extensible theorem proving in mainstream proof assistants by implementing an experimental Rocq plugin and studying its metatheoretical properties.
    }
    {\underline{\textbf{Publication}}: Jin, Ende, Nada Amin, and Yizhou Zhang. "Extensible Metatheory Mechanization via Family Polymorphism." Proceedings of the ACM on Programming Languages 7.PLDI (2023): 1608-1632. \hfill \url{https://github.com/DKXXXL/FPOP}}
