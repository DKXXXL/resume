\NewPart{Projects / Publications}{}

\ProjectEntry{Universal Quantification and Implication in miniKanren }{\url{https://github.com/DKXXXL/fo-mKanren-to-LF}}
{Racket, miniKanren}
{We extend the miniKanren (a logic programming DSL) with the ability of expressing universal quantification and logical implication. This can help to solve relational and logical query in a semi-decidable way, and thus become handy in the context of constraint solving and relation checking in programming. 
\underline{\textbf{Publication}}: Jin, Ende, et al. "Universal quantification and implication in miniKanren." Relational Programming Workshop. 2021. }


\ProjectEntry{Support Family Polymorphism for programming and theorem proving in Coq (Advisor : \href{https://cs.uwaterloo.ca/~yizhou/}{Yizhou Zhang})}{}
{OCaml, Coq}
{Family Inheritance generalizes Object Oriented Programming by supporting nested class and inheritance in various dimension. It shows its power as yet another solution to Expression Problem. This project is exploiting its potential on helping extensible theorem proving in mainstream proof assistants, by implementing an experimental Coq plugin and exploring meta-theoretical property.}

\ProjectEntry{CDCL Algorithm formalized in Coq, Parametrized }{\url{https://github.com/DKXXXL/ParaCDCL}}
{Coq, OCaml}
{CDCL algorithm is the very basis of modern day SAT/SMT solvers.  We formalize an extensible and parametric variant of CDCL algorithm (together with unsatisfiable proof generation) inside Coq. We also prove its correctness. Using Coq's facility, we check our prototype by initantiating it into DPLL and extracting the verified algorithm into OCaml.}
